# The Diagnostic Bay — Project Roadmap

**Last updated:** 2026-10-30  
**Working project label:** The Diagnostic Bay (not a finalized brand)  
**Budget baseline:** $0 unless the owner explicitly approves spending

## Stage 1 — Public educational resource

| Workstream | Current status | Notes |
|---|---|---|
| Responsive React/Vite website | Implemented on main | Current UI includes responsive navigation and content sections; runtime QA is pending. |
| Searchable diagnostic library | Implemented on main | Local curated data; no live vehicle connection or external code database. |
| Trouble-code explanations | Starter set implemented on main | Draft only; mechanic review and authoritative references are required before publication. |
| Symptom navigation and Guided Intake | Implemented on main | Observation gathering and stop-work guidance; not an automated diagnosis. |

| Technical references and item-level mechanic approvals | Not complete | Release blocker. |
| Spanish review and approved translations | Not started | Begins after mechanic approval. |
| Brand identity, logo, mascot and final production artwork | Provisional | Naming and creative assets remain subject to IP review and owner approval. |
| Browser, accessibility and end-to-end QA | Deferred to next phase | Owner requested completion of the build before the testing phase. |
| Production release | Not approved | No deployment is authorized by this roadmap. |

## Stage 2 — Better diagnostic experience

Planned after Stage 1 content and safety foundations are sound:
- More guided diagnostic workflows with clear stop-work boundaries.
- Improved vehicle and symptom navigation.
- Expanded educational resources.
- Accessibility and usability improvements informed by QA.

## Stage 3 — Potential premium capabilities

Exploratory only; no implementation or payments without a separately approved specification:
- Saved diagnostic histories.
- Advanced educational content.
- Individual, mobile-mechanic, and shop-oriented workflows.
- Any monthly or annual plans, memberships, billing, or account tiers.

## Release gates

1. Qualified mechanic approval for every public diagnostic item.
2. Authoritative references and vehicle-specific specifications where applicable.
3. Spanish review for translated content.
4. Brand/IP and legal review before finalizing the public identity.
5. Browser, accessibility, content, security, and performance QA with recorded evidence.
6. Separate explicit owner approval before merge/release/deployment or paid services.
