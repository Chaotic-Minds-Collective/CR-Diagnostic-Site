# Automotive Diagnostic Resource

This repository contains the first static website prototype for an evidence-led automotive troubleshooting and learning resource. **Burning Oil Garage is a working name only**; the final brand and helper name remain undecided.

## Run locally

Open `index.html` in a modern browser. For best local behavior, run a static server from the repository root, such as `python -m http.server 8000`, then visit `http://localhost:8000`.

## Included

- Responsive landing page and mobile navigation
- Search across draft trouble-code summaries and field guides
- Filterable trouble-code library with 12 draft entries
- Six interactive field-guide details
- Safety callouts, keyboard-friendly controls, and reduced-motion support
- No accounts, database, external API, analytics, payments, or deployment configuration

## Review status

The diagnostic content is draft educational material and must receive qualified mechanic review and authoritative technical references before public launch. A diagnostic trouble code is evidence, not proof that a particular component has failed. Vehicle-specific service information takes precedence.
